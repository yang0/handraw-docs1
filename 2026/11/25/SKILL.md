# 运镜提示词库（camera-move-prompts）

## 用途

把用户的创作意图（情绪、场景、想强调的东西）映射到具体运镜，并直接产出可粘贴进视频/出图模型的英文提示词。库内 38 条运镜全部来自飞书文档《各种运镜提示词》，每条都配有飞书视频参考地址，便于用户先看效果再决定。

## 何时使用

- 用户说"这个镜头怎么动""用什么运镜""帮我写运镜提示词"
- 用户要写分镜脚本 / shot list，需要给每个镜头指定镜头运动
- 用户想把中文运镜描述转成英文 prompt（Seedance、可灵、Veo、Sora、即梦等）
- 用户提到具体英文术语：dolly in/out、zolly、orbit、crane、pedestal、whip pan、dutch angle、FPV、rack focus、POV
- 用户要"高级感""电影感""紧张感""孤独感"等情绪化的镜头设计

## 工作流程

1. **先判断意图**：情绪（紧张/孤独/释然/震惊）、叙事功能（登场/揭露/转场/结尾）、空间条件（密闭/开阔/纵深/垂直空间）。
2. **选 1–2 条运镜**，不要堆砌。用下面的索引表或 `scripts/lookup.py` 定位。
3. **取原文**：从 `references/moves.md` 复制该条的完整英文提示词。提示词是可直接使用的模板句，**必须保留其英文原文**，不要自行改写；用户要定制时，只在原文基础上替换主体/环境/光线，并保留运镜动词（dolly-in、orbit、crane up 等）。
4. **附飞书视频地址**：每条都必须给出 `https://my.feishu.cn/file/<token>` 形式的视频参考链接（视频托管在飞书，不要另存、不要转贴其他来源）。
5. **输出格式**（默认）：

```
运镜：<编号> <中文名>
为什么选它：<一句话，绑定用户场景/情绪>
英文提示词：
<原文>
视频参考：<飞书视频地址>
```

6. 多镜头需求时，按镜头顺序输出，并在末尾给一条"衔接建议"（如推镜接后拉形成呼吸感、甩镜接甩镜做转场）。

## 资源

- `references/moves.md` — 38 条的完整原文：适用场景 + 英文提示词 + 飞书视频地址。**需要抄写提示词原文时读这个文件。**
- `data/moves.json` — 结构化数据（no/title/desc/prompt/video_token/video_name/video_url），供脚本或程序化调用。
- `scripts/lookup.py` — 检索器，避免把全库读进上下文：

```bash
python scripts/lookup.py --list            # 38 条编号 + 中文名 + 视频地址
python scripts/lookup.py 环绕               # 中文关键词
python scripts/lookup.py orbit drone       # 英文术语（内置 dolly/zolly/orbit/crane/FPV/whip pan 等同义词映射）
python scripts/lookup.py --no 4            # 取某条完整内容（含英文提示词与视频）
```

## 使用注意

- 视频链接为飞书文件地址，需登录同一飞书租户才能播放；对外分享时改为发送飞书文档链接 `https://my.feishu.cn/wiki/WopCwYlZRi20DwkWiwEcIf3Lnhb`。
- 11 号"模糊变清晰"原文档标注"视频有误"，且视频文件复用了 10.mp4，引用时说明这一点。
- 每段提示词是"运镜 + 主体 + 环境 + 光线"的组合模板：换主体换场景即可复用，但运镜动词与镜头语汇（dolly-in / orbit / crane / pedestal / tilt）不要替换成中文或同义改写，否则模型对运镜的识别会下降。
- 原始文档标题标注"（待增加）"，后续若用户提供新增条目，追加到 `references/moves.md` 与 `data/moves.json`（保持 no 递增与同一字段结构），并同步更新本文件的索引表与场景速查。
