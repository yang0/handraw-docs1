本项目规则用于生成 Amazon A+ 页面、电商详情页切片、场景合成图，以及在用户要求时生成 Photoshop JSX 自动建稿文件。
本规则以“稳定出图”为第一优先级，避免草稿图、PPT 风、线框图、模板图。

一、项目定位

本项目用于根据用户每次上传的产品图片，生成适合该产品的 Amazon A+ / 电商详情页图片。

核心目标：
1. 输出可直接用于电商详情页的最终成品图。
2. 不固定套用某一种产品模板，而是根据产品类型和素材情况动态规划模块。
3. 每个模块单独成图。
4. 所有页面默认使用英文内容。
5. 页面整体应专业、现代、简洁、高级，适合成熟电商品牌。
6. 输出应适合上下拼接成长详情页，不要像 PPT 页面。

适用产品：
运动器材、灯具、碳纤维汽车件、户外用品、救援用品、家居用品、工业配件、消费品等。

二、总执行原则
1. 必须先识别产品类型、外观特征、素材状态和主要卖点。
2. 如果用户提供了文案，优先按照用户文案和产品特征规划详情页结构。
3. 不得套用固定产品结构，不同产品必须有不同 A+ 结构。
4. 模块数量必须为双数，例如 4、6、8、10、12，不能是奇数。
5. 模块数量根据产品信息量自动决定，不要为了凑数量而重复内容。
6. 信息量大的板块可以拆成两个模块，例如 Material 和 Craft 分开，Detail Close-up A 和 B 分开。
7. 不默认加入 Factory /工厂实力 / 企业宣传模块，除非用户明确要求。
8. 必须加入至少 1 个场景合成模块，用于展示产品在实际使用环境中的视觉效果。
9. 每张图只表达一个核心主题，不能把多个无关卖点塞进同一张图。
10. 不要中途停下来等待确认，除非缺少关键输入。
11. 必须一次性完成完整流程，直接输出完整结果。
12. 每张图都必须是最终成品图，不得输出半成品、草稿图、PPT 风页面、线框图或示意图。

三、产品一致性规则

1. 产品主体必须以用户上传的产品图为准。
2. 用户提供 PNG 产品图时，产品本体应作为固定素材使用。
3. 如果要保证产品 100% 不变，必须采用“背景生成 + 产品 PNG 合成”的流程，而不是直接让 AI 重画产品。
4. 场景合成时，正确流程是：先生成背景 / 场景，再把用户产品 PNG 作为独立图层合成进去。
5. 不要让 AI 直接重新生成“场景 + 产品本体”的完整图，除非用户明确允许产品可能变化。

允许对产品做：
- 抠图
- 缩放
- 旋转角度微调
- 裁切
- 局部特写
- 阴影
- 高光
- 接触阴影
- 背景融合光效
- 多视角组合

禁止对产品做：
- 改形状
- 改孔位
- 改颜色
- 改结构
- 改纹理
- 重新生成类似产品
- 擅自换成另一种型号、颜色或外观结构

四、模块规划规则

1. 每套详情页必须根据产品自动选择模块。
2. 所有产品至少需要包含：
   - Hero Banner
   - Core Selling Points 或 Performance / Function
   - Specifications / Dimensions
   - Usage Scenario Banner
3. 如果产品是碳纤维类、工艺类、结构类产品，优先增加：
   - Material
   - Craft / Process
   - Construction Breakdown
   - Detail Close-up
4. 如果产品用于电商转化，优先增加：
   - Core Selling Points
   - Usage Scenario Banner
   - Detail Close-up
   - Packaging / What’s Included
5. 如果产品有多个型号或 SKU，增加：
   - Comparison / Variant
6. 如果信息多，拆成两个模块，不要压缩到一张图。
7. 模块数量必须保持双数。

五、动态模块库

M1 Hero Banner
用途：第一屏主视觉，建立产品第一印象。
适合：所有产品。
内容：产品主图、主标题、副标题、3 个核心短卖点。
画面结构：产品大图占 50%~70%，文案一侧排布，背景干净、统一、连续。

M2 Core Selling Points
用途：快速讲清产品为什么值得买。
适合：外观型、功能型、电商型产品。
内容：3~4 个核心卖点，每个卖点包含小标题 + 1 句短描述。
画面结构：左图右文 / 中间产品 + 四周卖点 / 图标 + 短句 + 简说明。

M3 Material
用途：讲材料。
适合：材料有卖点的产品、碳纤维产品、工艺型产品。
内容示例：Carbon Fiber Face、EVA Core、Reinforced Frame、Surface Finish。
画面结构：产品局部特写、材料说明、材质纹理图。

M4 Craft / Process
用途：讲工艺与制造过程。
适合：工艺感强的产品。
内容示例：Molding、Drilling、Surface Finishing、Edge Treatment、Structural Stability。
画面结构：流程图、局部结构图、工艺标注图。
注意：除非用户要求，不要做成工厂宣传页。

M5 Construction Breakdown
用途：讲内部结构或分层结构。
适合：球拍、板材、担架、机械件、汽车部件。
内容示例：Surface Layer、Core Layer、Reinforcement Layer、Edge Protection、Handle / Joint / Connector。
画面结构：中心主物体 + 周围标注箭头 + 每层 1 行说明。

M6 Detail Close-up
用途：展示细节，增加真实感和高级感。
适合：所有需要质感表达的产品。
内容示例：表面纹理、边缘处理、握把、连接处、细节工艺。
画面结构：2~4 个特写框，每个特写配短标题。

M7 Performance / Function
用途：强调功能效果。
适合：有明确性能表达的产品。
内容示例：Power、Control、Balance、Load Capacity、Foldable Structure、Aerodynamic Support。
画面结构：数据条、图标、动作图、功能说明。

M8 Usage Scenario Banner
用途：讲产品在哪用、给谁用，增强代入感。
适合：场景型产品、运动产品、户外产品、家居产品。
内容：使用场地、人群、应用环境、实际体验。
画面结构：大场景图 + 产品 PNG 合成 + 小标签说明。
注意：产品必须作为独立 PNG 合成，不允许 AI 重绘产品。

M9 Specifications / Dimensions
用途：讲参数、尺寸、重量、材料。
适合：几乎所有产品，尤其是电商产品和 B2B 产品。
内容示例：Shape、Weight、Length、Thickness、Surface、Core、Balance、Finish。
画面结构：参数表、产品尺寸示意、线稿标注。
硬性要求：整套详情页中必须包含 1 张产品尺寸 / 尺寸示意 / 规格尺寸模块。

M10 Comparison / Variant
用途：展示多个型号或版本。
适合：多 SKU 产品。
内容：型号 A / B / C、不同颜色、不同尺寸、不同材质版本。
画面结构：横向对比、卡片式对比、简表格对比。

M11 Packaging / What’s Included
用途：展示包装内容。
适合：电商产品、需要完整交付说明的产品。
内容示例：1 × Product、1 × Cover / Bag、1 × Accessory、1 × Manual。
画面结构：产品 + 配件平铺 + 简洁说明。

M12 Trust / Quality Assurance
用途：增强信任。
适合：高客单价、工艺型产品、需要质检说明的产品。
内容示例：Strict QC、Stable Quality、Consistent Finish、Reliable Materials。
画面结构：简洁图标、质检流程位、品控说明。
注意：不要做成工厂实力宣传页。

六、文案规则

1. 所有文案默认使用英文。
2. 文案必须短，适合放在图片里。
3. 主标题尽量 3~6 个词。
4. 副标题尽量 1 句。
5. 卖点不超过 3~4 个。
6. 不写长段落，不写大段说明文字。
7. 每张图只表达一个核心主题。
8. 文案风格要像成熟品牌详情页，简洁、有力、清晰。
9. 不要堆砌营销套话。
10. 不要生成过于空泛、与产品无关的词句。
11. 不默认写 OEM / Factory / ODM。
12. 如果某页信息偏多，必须拆分成两个模块，而不是强行挤在一张图里。

文案去重规则：
1. 每个模块的核心文案必须表达不同信息。
2. 禁止多个模块反复表达同一个意思，例如反复使用 control / stable control / precise control，或 lightweight / easy swing / quick handling。
3. 每个模块必须有独立信息角色，例如 Hero、Material、Structure、Detail、Grip、Dimensions、Scenario。
4. 如果两个模块文案表达接近，必须自动重写其中一个。
5. 不要为了凑模块数量而重复同类卖点。

七、字体与字号规则

1. 默认使用 Arial 字体族。
2. 只使用三种字重：
   - Arial Regular
   - Arial Bold
   - Arial Black
3. 默认只使用三档字号：
   - 44 px：主标题 / Hero Title / 一级标题
   - 32 px：模块标题 / 二级标题 / 重点短语
   - 18 px：正文 / 副标题 / 卖点说明 / 参数文字
4. 不随意增加其他字号，除非用户明确要求。
5. 如果 Arial 不可用，可以使用 Google 免费英文字体作为替代，例如 Roboto、Montserrat、Inter、Open Sans、Poppins。
6. 替代字体也必须保持相同字号体系：44 / 32 / 18。
7. 图片内文字要简短，优先保证可读性，不使用过细字体。
8. PSD / JSX 输出时，文字层必须保持可编辑，并尽量指定 Arial / ArialMT。
9. 本次图片主要用于手机端浏览，文案必须进一步精简。
10. 单张图文字数量要少，优先保证标题清晰、卖点易读。
11. 参数和说明不得过密，不允许出现小字堆叠。

八、版式规则

1. 每个模块必须有独立版式，不允许整套页面反复使用同一种版式。
2. 禁止所有页面都使用固定的“左文右图”或“左图右文”模式。
3. 禁止所有页面都使用相同标题位置、卖点位置和产品摆放方式。
4. 相邻模块之间必须避免版式重复。
5. 同一种版式逻辑不得连续重复。
6. 页面必须根据当前模块内容选择版式，不得全套套版。

可用版式包括但不限于：
- Hero Banner
- 左文右图
- 左图右文
- 中心标题 + 两侧信息
- 中心产品 + 四周信息点
- 大图主导 + 局部文案
- 局部特写 + 辅助信息
- 上文下图
- 上图下文
- 大场景图 + 文字信息区
- 参数表格式布局
- 尺寸图版式
- 对角线构图
- 多视角组合
- 极简留白版式

版式执行硬规则：
1. 相邻页面必须换版式。
2. 同一种版式不得连续出现。
3. 同一种背景逻辑 + 同一种文字区逻辑 + 同一种产品摆位，不能重复组合。
4. 就算内容不同，只要页面骨架一致，也视为重复版式。
5. 每页必须至少在以下 3 项上与上一页不同：产品位置、文字区位置、标题位置、背景风格、构图重心、视角类型、信息组织方式。

九、背景与视觉语言规则

1. 背景要干净、有留白、适合拼接成长页面。
2. 整套详情页禁止反复使用同一种背景逻辑。
3. 禁止连续使用“左侧文字区 + 左向右渐变过渡 + 右侧产品图”的固定视觉模板。
4. 禁止整套页面都使用同一种左→右渐变背景。
5. 禁止每张图都在左侧铺一层雾化白底来承载文字。
6. 每个模块必须主动变化背景的明度、类型、空间层次与重心。

整套页面建议混合使用 5 种以上不同背景 / 视觉语言：
- 纯白背景
- 纯浅灰背景
- 深色纯底背景
- 局部聚光背景
- 中心扩散渐变
- 径向渐变
- 对角渐变
- 上下渐变
- 场景实景背景
- 局部纹理背景
- 技术感线条背景
- 几何块面背景
- 高留白背景
- 局部阴影背景
- 材质底纹背景

每个模块至少变化以下 3 项以上：
- 背景明度：浅 / 中 / 深
- 背景类型：纯底 / 渐变 / 场景 / 纹理 / 技术线条
- 渐变方向：横向 / 纵向 / 对角 / 中心扩散
- 空间层次：平面 / 景深 / 光影
- 视觉重心：左 / 右 / 中 / 对角
- 背景细节密度：极简 / 中等 / 丰富

十、图标与装饰规则

1. 图标只能作为辅助信息元素，不能成为页面主视觉。
2. 单张页面图标数量建议 0~3 个。
3. 非必要时可不使用图标。
4. 禁止每个卖点都强行配一个图标。
5. 禁止把图标列表作为固定模板重复使用。
6. 参数表、功能拆解页、少量卖点页，可以少量使用图标。
7. Hero Banner、场景页、尺寸页、细节特写页，原则上应尽量少用或不用图标。
8. 图标风格必须统一、简洁、线性化、克制。
9. 如果图标不能明显提升信息表达，直接删除。

图标上限：
- 整套详情页，图标总数建议不超过 6 个。
- 单张图最高不超过 3 个。

十一、图片生成规则

1. 如果用户要求生成图片，必须按模块逐张输出，每个模块只生成 1 张独立成品图。
2. 不要把多个模块拼成一张总览图。
3. 每张图必须独立适配可生成最大尺寸。
4. 图片要适合拼接成长详情页。
5. 背景要连续、干净、有留白。
6. 产品 PNG 必须保持不变。
7. 如果需要场景图，先生成背景，再合成产品 PNG。
8. 最终输出必须是可直接使用的最终成品图，不是草稿图、模板图、PPT 风页面或线框图。

十三、PSD / Photoshop JSX 输出规则

当用户要求 PSD 或 Photoshop 可编辑文件时，优先生成可在 Photoshop 中运行的 JSX 自动构建脚本。

PSD / JSX 基本规则：
1. 画布宽度固定为 1000 px。
2. 单个模块高度固定为 500 px。
3. 总画布高度 = 模块数量 × 500 px。
4. 所有模块按顺序从上到下排列。
5. 每个模块必须建立独立图层组。
6. 每个模块的 Y 坐标为：模块序号 × 500 px。
7. 每 500 px 添加参考线。
8. 文本使用 Arial / ArialMT，保持可编辑。
9. 产品、背景、文案、图标、阴影尽量分层。
10. 底部必须有白色背景，不使用伪透明，不使用棋盘格透明效果。

每个模块建议图层结构：
- Background：完整背景图层
- Product：产品图层
- Text_Title：可编辑标题文字
- Text_Subtitle：可编辑副标题文字
- Text_Bullets：可编辑卖点文字
- Guide / Dimension：尺寸线或辅助说明图层，如有

重要限制：
1. 如果只提供最终成品图，没有真实分层素材，不要声称可以真实拆层。
2. 可以生成 Final_Render_Reference_VISIBLE 作为最终成品图参考层。
3. 可以重建可编辑文字层。
4. 可以使用已提供或已同步保存的背景图、产品 PNG、效果图层进行重建。
5. 不要创建空的 Background / Product / Effects 分组冒充真实分层。
6. 不要输出 placeholder 文件夹充当真实素材。
7. README 必须说明素材来源和是否为真实分层。

十四、最终检查规则

生成整套详情页前后，必须检查：

1. 模块数量是否为双数。
2. 是否缺少尺寸 / 规格模块。
3. 是否缺少场景合成模块。
4. 产品主体是否保持一致。
5. 是否擅自改变产品颜色、形状、孔位、结构或纹理。
6. 是否有相邻页面版式重复。
7. 是否多张页面出现相同左文右图骨架。
8. 是否背景逻辑过于重复。
9. 是否图标过多。
10. 是否文案过长、过满、过挤。
11. 是否多个模块文案表达重复。
12. 是否每张图都是 1000 × 500 px。
13. 是否像最终电商详情页，而不是 PPT、草图或模板图。

十五、最高优先级提醒


1. 最终成品图质量优先。
2. 产品一致性优先。
3. 不要为了规则而牺牲画面完成度。
4. 不要为了后期 PSD / JSX 拆层而降低最终图质量。
5. 出图任务和 PSD / JSX 任务应分开理解：
   - 先保证最终图能直接用于 A+ 页面。
   - 用户要求 PSD / JSX 时，再基于最终图和已有素材生成可编辑项目。
6. 不要输出低质量模板图。
7. 不要输出看起来像 PPT 的页面。
8. 不要重复同一套版式、背景和卖点。
